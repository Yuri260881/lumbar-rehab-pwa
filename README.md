# Lumbar Rehab Dashboard

Офлайн-первое PWA для домашней реабилитации при грыже поясничного отдела позвоночника: дневник состояния, программа упражнений с источниками, секундомер для статических упражнений, напоминания и отдельный учёт инверсионного стола через день.

> ## Медицинский дисклеймер
>
> **Приложение не лечит грыжу.** Оно не ставит диагноз, не назначает лечение, лекарства, дозировки или процедуры и не обещает «устранение», «рассасывание» или гарантированное излечение грыжи.
>
> Формулировка, которой придерживается приложение: **поддержка реабилитации и уменьшение симптомов по согласованию с врачом**.
>
> Перед началом занятий программу желательно согласовать с врачом, неврологом или физиотерапевтом. Приложение показывает это предупреждение до первого упражнения и не пропускает пользователя дальше без подтверждения.
>
> Приложение **не является медицинским изделием**. Все данные хранятся только на устройстве пользователя.

## Быстрый старт

Требуется Node.js 20.11+ (разработка велась на Node 20.20.2 / npm 10.8.2).

```bash
npm install
npm run dev          # http://localhost:5173
```

Проверки:

```bash
npm run typecheck    # tsc --noEmit
npm run lint         # eslint (включая jsx-a11y)
npm run test         # vitest (логика + UI-тесты безопасности)
npm run build        # typecheck + vite build
npm run check        # всё сразу
```

Иконки (нужен ImageMagick, генерируются из `public/icons/icon.svg`):

```bash
npm run icons
```

Smoke-тест в реальном браузере (Puppeteer + headless Chrome; входит в devDependencies,
Chrome скачивается при установке):

```bash
npm run build && npm run preview &   # или `npm run dev` на 5173
npm run smoke                        # 24 проверки + скриншоты в .smoke/
```

Проверяется: стартовое предупреждение и скрининг, отсутствие горизонтального
скролла на 360 px, Service Worker и офлайн после первой загрузки, источники в
карточках, пауза/продолжение/сброс/переход между подходами, сохранение дневника
в IndexedDB и перезагрузка, блокировка упражнений при тревожных симптомах,
честные ограничения уведомлений, гейт инверсионного стола.

## Production build и локальный просмотр

```bash
npm run build
npm run preview      # http://localhost:4173
```

`dist/` — статический сайт. Подходит любой статический хостинг с HTTPS (обязателен для Service Worker и уведомлений).

## Установка как PWA

- **Android (Chrome):** меню браузера → «Установить приложение» / «Добавить на главный экран».
- **iOS / iPadOS (Safari):** «Поделиться» → «На экран „Домой"». Только Safari и только iOS 16.4+ поддерживают веб-уведомления, и только после установки на главный экран.
- **Desktop (Chrome/Edge):** иконка установки в адресной строке.

После первой загрузки приложение работает офлайн: оболочка и все данные упражнений кэшируются Service Worker'ом.

## Модель данных

Всё хранится в одном объекте `AppData` в IndexedDB (`lumbar-rehab` → object store `kv` → ключ `app-data`), с фолбэком на `localStorage` и, если недоступно и оно, на память вкладки.

| Сущность | Что содержит |
|---|---|
| `Preferences` | подтверждение дисклеймера, имя, состав программы, настройки таймера, напоминания, флаг разрешения врача на инверсию, reduced motion |
| `DiaryEntry` | дата, боль 0–10, онемение, слабость, качество сна, выполненные упражнения, реакция через несколько часов, комментарий |
| `WorkoutSession` | дата, начало/конец, состав и фактически выполненные упражнения, длительность |
| `InversionSession` | дата, статус (`done`/`skipped`), самочувствие после, отметка о тревожных симптомах |
| `RedFlags` | шесть булевых полей тревожных симптомов + дата последней проверки |
| `ScheduledReminder` | тип, заголовок, текст, время, признак отправки |

Сервера нет: ни один байт не уходит наружу. Экспорт JSON/CSV формируется на устройстве.

## Функциональность

**Главный экран (Dashboard)**
приветствие, сегодняшняя программа и прогресс, ближайшие напоминания (всегда видимые, даже без разрешения на уведомления), кнопка «Начать тренировку», карточка самочувствия, последний показатель боли 0–10, напоминание об инверсионном столе, рекомендация дня, блок предупреждений и ограничений.

**Библиотека упражнений** — 7 категорий: мягкая разминка, мобильность поясничного отдела, стабилизация корпуса, укрепление живота и ягодиц, растяжка, статические упражнения, восстановление и дыхание. Всего 22 упражнения — каждое только из авторитетного источника. Карточка содержит: название, назначение, оригинальный SVG-эскиз, исходное положение, пошаговую технику, дыхание, повторения/удержание, подходы, отдых, уровень сложности, противопоказания, сигналы остановки, источник с прямой ссылкой и датой проверки.

**Секундомер** — обратный отсчёт, пауза, продолжение, сброс, переход к следующему подходу, отдых между подходами, звуковой сигнал (Web Audio, без файлов), вибрация, настраиваемая длительность удержания и число подходов, индикатор текущего подхода, крупные элементы управления (≥ 56 px), Screen Wake Lock. Если звук, вибрация или Wake Lock недоступны — всё продолжает работать без них, а интерфейс честно сообщает об этом.

**Напоминания** — ежедневное утреннее напоминание о тренировке, напоминание об инверсионном столе через день, настройка времени, включение/выключение, откладывание, отметка «выполнено», история тренировок. Используются Web Notifications API и Service Worker (`periodicsync`, если браузер его поддерживает) плюс **резервное отображение напоминаний внутри приложения**, которое работает всегда.

**Инверсионный стол** — календарь через день, напоминание о следующем сеансе, чек-лист из 8 пунктов, пропуск дня, журнал самочувствия, список противопоказаний и сигналов немедленной остановки. Угол наклона и длительность приложение **намеренно не задаёт**: в сессии фиксируются только статус (`done`/`skipped`), самочувствие после, комментарий и отметка о тревожных симптомах.

**Рекомендации** — 10 общих рекомендаций, каждая со ссылкой на источник (NHS, NICE, AAOS, AANS, Mayo Clinic, Cleveland Clinic, ACP, рецензируемые публикации).

**Дневник** — боль 0–10, онемение, слабость, качество сна, выполненные упражнения, реакция через несколько часов, комментарий, экспорт JSON/CSV, удаление записей.

**Безопасность** — раздел «Когда необходимо срочно обратиться за медицинской помощью» (потеря контроля над мочеиспусканием/кишечником, онемение в промежности, быстро нарастающая слабость в ноге, внезапная потеря чувствительности, сильная боль после травмы, температура и другие тревожные симптомы). При любой активной отметке приложение **скрывает упражнения и не предлагает тренировку**, показывая предупреждение обратиться за помощью.

## Ограничения уведомлений (важно)

Ни один браузер не гарантирует доставку веб-уведомления при полностью закрытом приложении. Приложение не использует фоновые механизмы, которые браузер не может обеспечить, и всегда дублирует напоминания внутри интерфейса.

| Платформа | Что работает | Что не работает |
|---|---|---|
| **Android (Chrome)** | Уведомления при выданном разрешении; периодическая синхронизация — только для установленных PWA с достаточной «вовлечённостью» | Энергосбережение системы может задерживать или подавлять уведомления |
| **iOS / iPadOS** | Уведомления только в PWA, установленном на главный экран через Safari (iOS 16.4+) | В обычном браузере уведомлений нет вообще; при долгом неиспользовании устройства они тоже не приходят |
| **Desktop Chrome/Edge** | Уведомления, пока вкладка открыта или PWA установлено | После закрытия окна доставка не гарантирована |
| **Firefox** | Поддержка ограничена | Планирование в фоне недоступно |
| **Все платформы** | Требуется HTTPS (или localhost) и явное разрешение пользователя | `localhost` вне песочницы, `http://` — уведомления недоступны |

Этот же список показывается пользователю в разделе «Напоминания» вместе с фактическим статусом: API, разрешение, secure context, состояние Service Worker, установлено ли PWA.

## Доступность (WCAG 2.2 AA)

- Семантическая разметка, skip-link, `aria-label`, `aria-live` для состояния таймера, `role="switch"`, `aria-pressed` у фильтров.
- Полная навигация с клавиатуры, видимый фокус-индикатор 2 px с контрастным цветом.
- Целевые области ≥ 44 × 44 px (основные кнопки таймера — 56 px).
- Контраст текста ≥ 4.5:1, крупные цифры таймера ≥ 3:1.
- `prefers-reduced-motion` уважается глобально + отдельный переключатель в настройках.
- Отсутствие горизонтального скролла: `overflow-x: hidden` на `body`, адаптивная сетка, `min-w-0` у flex-потомков.
- Все иллюстрации — собственные SVG с `role="img"` и текстовым `aria-label`; случайные картинки из интернета не используются.

## Конфиденциальность

- Нет сервера, аналитики, трекеров, сторонних скриптов и веб-шрифтов.
- Медицинские данные не покидают устройство.
- Ссылки на источники открываются в новой вкладке с `rel="noopener noreferrer"`.
- В репозитории нет секретов, токенов и персональных данных.
- Полное удаление локальных данных — в настройках, с двойным подтверждением.

## Известные ограничения и принятые решения

1. **Уведомления не гарантированы (безопасность → осторожный вариант).** Выбран наиболее осторожный вариант: резервный список напоминаний внутри приложения — основной механизм, системные уведомления — дополнение.
2. **Инверсионный стол — только как опция.** Раздел открывается после явного подтверждения разрешения врача; приложение не задаёт угол и длительность, потому что это медицинское решение. Основание: NICE NG59 не рекомендует тракцию; ACP указывает на недостаточность доказательств эффективности инверсии.
3. **Нет индивидуальных назначений.** Приложение не подбирает упражнения и не даёт рекомендаций по одному симптому — оно показывает источник и предлагает обратиться к специалисту.
4. **Направление упражнений индивидуально.** Упражнения в разгибании (`press-up`, разгибание стоя) помечены как «повышенной сложности», не входят в программу по умолчанию и сопровождаются явным предупреждением.
5. **Программа по умолчанию — мягкая.** В неё входят только упражнения уровня `gentle`; статика и сложные упражнения добавляются пользователем сознательно.
6. **Данные живут в одном браузере.** Смена устройства или очистка данных браузера удаляет записи — предусмотрен экспорт JSON/CSV.
7. **Дата проверки источников — 24.09.2026.** Ссылки могут измениться; приложение продолжает работать офлайн, но цитирование стоит периодически обновлять.
8. **Русская локализация.** Интерфейс и медицинские тексты на русском, названия упражнений дублируются английскими терминами из источников.
