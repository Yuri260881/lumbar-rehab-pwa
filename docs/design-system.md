# Дизайн-система Lumbar Rehab Dashboard

Визуальный язык: медицинско-оздоровительный, «тихая премиальность». Не больничная стерильность и не игровая мотивация — спокойный инструмент для ежедневного самоконтроля.

## Принципы

1. **Контраст важнее эффекта.** Каждая пара «текст/фон» подбирается под WCAG 2.2 AA (≥ 4.5:1 для обычного текста, ≥ 3:1 для крупных надписей и графики).
2. **Один акцент на экран.** Золотой — основное действие и прогресс; бирюзовый — спокойный, «готово», фаза отдыха; красный — только тревожные симптомы и немедленная остановка.
3. **Никакой геймификации.** Нет бейджей, очков, наград и «стриков». Прогресс — это факты: последняя запись боли, число тренировок, выполненные подходы.
4. **Большие цели, короткие действия.** Приложение рассчитано на человека с болью: минимум мелких нажатий, крупные элементы управления таймера, понятный следующий шаг.
5. **Иллюстрации — собственные.** Все эскизы нарисованы в этом репозитории из простой геометрии в едином стиле. Скачанных картинок нет.

Фон задаётся в `src/index.css`: `radial-gradient` с очень мягким бирюзовым пятном сверху (`rgba(79,191,169,0.08)`) поверх `linear-gradient(180deg, #0b0f14 0%, #06080b 100%)`, `background-attachment: fixed`. Горизонтального скролла нет: `overflow-x: hidden` на `body` (WCAG 1.4.10), `min-w-0` у flex-потомков, `break-words` у длинных ссылок.

### Как добавить светлую тему

Палитра изолирована в токенах, семантика — в классах `.card`, `.card-pad`, `.btn-primary` / `.btn-secondary` / `.btn-ghost` / `.btn-danger`, `.chip`, `.hint`, `.label`, `.stack` (все в `@layer components` файла `src/index.css`). Достаточно объявить альтернативные значения `ink.*` / `gold.*` под `[data-theme="light"]` и переопределить три правила с `border` и `background`; разметка компонентов не меняется. Сейчас `:root { color-scheme: dark }` — при добавлении темы его нужно перевести на CSS-переменную.

## Типографика

Системный стек: `system-ui, -apple-system, "Segoe UI", Roboto, "Helvetica Neue", Arial, "Noto Sans", sans-serif`; моноширинный — `ui-monospace, SFMono-Regular, "SF Mono", Menlo, Consolas, "Liberation Mono", monospace`. Веб-шрифты не подключаются: ни одного внешнего запроса, первая отрисовка мгновенная.

| Уровень | Классы | Применение |
|---|---|---|
| Заголовок экрана | `text-2xl font-semibold tracking-tight` | название раздела |
| Заголовок карточки | `text-base font-semibold` | название блока |
| Основной текст | `text-sm leading-relaxed` | техника упражнения, рекомендации |
| Подсказка | `.hint` → `text-sm leading-relaxed text-ink-300` | подписи, метаданные |
| Метка формы | `.label` → `text-sm font-medium text-ink-200` | подписи полей |
| Крупная цифра | `font-mono text-[5.5rem] sm:text-[7rem] tabular-nums` | секундомер |
| Метрика | `font-mono` + `text-xl` | боль, серии, счётчики |

Моноширинный шрифт и `tabular-nums` используются для чисел, чтобы ширина не «прыгала» при обратном отсчёте. Заголовки получают `text-wrap: balance`, абзацы — `text-wrap: pretty`.

## Состояния

- **Focus.** `:focus-visible` → `outline: 2px solid gold-300`, `outline-offset: 2px` — заметно на тёмном фоне и не сливается с золотыми кнопками.
- **Hover / Active.** Изменяются только цвет границы и фон (`transition-colors`); трансформаций и «всплываний» нет.
- **Disabled.** Кнопка остаётся в потоке с `opacity-50` и `cursor-not-allowed`, причина объясняется текстом рядом (например, «Сначала подтвердите предупреждение»).
- **Опасное состояние.** Красная рамка, `role="alert"` и `aria-live="assertive"`.
- **Недоступная возможность.** Если звук, вибрация, Wake Lock или уведомления не поддерживаются, интерфейс показывает причину, а не скрывает её.

## Анимация и движение

Переходы — только цвета и границ, 160 мс (`transition-colors`, утилита `.motion-safe-anim`). Есть одна мягкая анимация `pulse-soft` (2 с) для активного состояния таймера. При `prefers-reduced-motion: reduce` все анимации и переходы обнуляются глобальным правилом в `index.css` (WCAG 2.3.3); тот же эффект включается переключателем «Уменьшить анимацию» в настройках через класс `.reduced-motion` на корневом контейнере.

## Адаптивность

Mobile-first: базовая вёрстка рассчитана на 360 px.

| Ширина | Поведение |
|---|---|
| ≤ 639 px | одна колонка, нижняя навигация, крупные карточки |
| ≥ 640 px (`sm`) | блоки программы и прогресса переходят в две колонки (`grid gap-4 sm:grid-cols-2`), отступы экрана увеличиваются с `px-4` до `px-6` |
| ≥ 1024 px | контент центрирован в контейнере `max-w-app` (72 rem), навигация остаётся снизу |

Приложение сознательно не превращается в «десктопный сайт»: на широком экране контент просто центрируется, а нижняя навигация сохраняется — интерфейс одинаково предсказуем на телефоне и планшете.

## Иллюстрации

`ExerciseSketch` рисует позы из простой геометрии: контур тела, руки, ноги и реквизит (коврик, опора) описаны полилиниями на поле 200 × 120, линия 2 px, `stroke-linecap="round"`. Цвет тела — золотой, целевые структуры упражнения подсвечиваются бирюзовым через `highlight`. Эскиз подписан для скринридеров (`role="img"` + `aria-label` с названием упражнения), поэтому смысл не теряется без изображения.

Иконки приложения — собственные: исходник `public/icons/icon.svg`, PNG-варианты (192, 512, maskable, apple-touch, badge, splash 1290 px) генерируются командой `npm run icons` скриптом `scripts/generate-icons.mjs` через ImageMagick.
